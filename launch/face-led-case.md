# Portrait-led recorded case

Prepared 2026-11-04 for Jazz. This is a creative hypothesis, not a performance result.

## What prompted the experiment

Jazz supplied a screenshot of an X post sharing `Alisa0808/vox-director`. It combines a human profile image, a concrete one-line-topic-to-finished-video promise, GitHub social proof, and third-party amplification. The screenshot alone does not isolate the image's effect. A read-only [GitHub API observation](https://api.github.com/repos/Alisa0808/vox-director) at 2026-11-04 08:37 KST returned 2,605 stars and 365 forks. The screenshot's rounded 3k card is not an exact current API count.

The [reference README](https://github.com/Alisa0808/vox-director#readme) places a completed 30-second video and four additional examples near the top. That observable packaging informs this case: show the result immediately and make the input/output inspectable. It does not establish which distribution action caused its stars.

## This experiment

- Original AI-generated adult portrait for a fictional Mina Studio design service. [Generation provenance](../docs/mina-portrait.md).
- One source brief, three actual skill recommendations, unchanged portrait and layout. [Raw output](../docs/evaluation/mina-demo/output.md).
- The first completed output is rendered verbatim. The service is fictional; the agent execution is actual. Neither is customer proof or a conversion test.
- A separate [actual audit](../docs/evaluation/current-page/output.md) applies Story to Landing Page Lab itself. Its input and instructions are recorded independently of the portrait example.
- The 14-second clip starts with a complete result. It does not stage a live model call or invent generation timing.

## Read the next result

Record actual impressions, link clicks, video views/retention, reposts/bookmarks, and net repository stars in the same dated window. X views are not unique people or completed video views. The current sample is small; zero clicks is an observed count, not a diagnosis of one cause. The portrait, source proof, opener, runtime and result timing all change together, so this is a directional creative test rather than a controlled face-effect experiment.

An improvement in views alone is insufficient. The useful next signal is a relevant visitor opening the repository, then an external founder running a skill and reporting what happened. Maintainer checks do not count as adoption. Keep unknown measures blank and do not ask for stars in exchange for access.
