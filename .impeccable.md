# Design Context

## Product direction

- Audience: English-speaking solo founders and developers who build products with AI coding agents.
- Job: make an existing product brief or README into a useful landing-page message, then use it in their existing build.
- Public language: English first.
- Marketing tone: direct and conversational, with a clear first line and a visible result.
- Presentation: show the actual work before asking the visitor to read the method.
- Keep accurate credits to Miller, Godin, and Hormozi without official affiliation claims.

## Implementation choices for this iteration

- Result first: a genuine plain-prompt output beside a genuine skill-assisted output, using the same brief and visual shell.
- Reuse the original AI-generated adult portrait and clearly identify the fictional demo.
- Keep the existing warm paper, dark green, and editorial typography. Use clear type hierarchy and restrained motion.
- Make the immediate difference readable, then offer one useful next step. Put detailed provenance behind a disclosure.
- Preserve raw outputs. Do not manufacture a weak baseline, a winner, customer proof, or performance metrics.
